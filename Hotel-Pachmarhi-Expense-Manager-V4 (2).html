How to set up Drive + GitHub Pages (one-time setup)
  1. Go to console.cloud.google.com → Create Project → Enable Google Drive API
  2. APIs & Services → Credentials → Create OAuth Client ID → Type: Web application
  3. Authorized JavaScript origins: add https://YOUR-USERNAME.github.io and http://localhost:8000
  4. Copy Client ID → Paste above → Click Connect Drive → Allow Drive access
  5. First system: Click Sync Now → Creates file on Drive. Other systems: Paste same Client ID → Connect → Pull from Drive → Same file appears.
  6. Upload this HTML to GitHub → Settings → Pages → Deploy from main branch. Share link.
Privacy: Token stays in your browser (sessionStorage). File is private to the Google account that connects. Share Drive file with staff accounts via Drive Share button for multi-system access. Offline changes remain in the recovery cache. On reconnect, records are reconciled by transaction ID and deletes are retained. Simultaneous edits are guarded by Drive revision checks; review any reported conflict.
